# Data lives only on the device

All Projects and Steps are stored in the browser on the person's phone. There is no account, server or sync, and a manual "Export backup" is the only safety net. We chose this because v1 is for one person on one phone, has to work offline and open instantly, and would lose its "zero setup" start if it asked for a sign-up. Adding sync later means adding accounts and a backend, so it's a big step, not a toggle.
