## Things to know before changing code

- **Architecture:** plain JS, no framework.
  - `src/main.js` handles hash routing (`#now`, `#projects`, `#project/<id>`, `#new`, `#settings`) and the event wiring.
  - Each screen module exports `view(app, param)` and `actions`. Elements name their action with `data-action` (clicks), `data-form` (submits) or `data-change` (file inputs).
- **All data rules are pure functions** in `src/store.js`, with tests at the seams the user approved: store, `braindump.js`, `firstmoves.js` and `backup.js`. Use `tdd` for changes there, and run `npm test` (Node's built-in test runner).
- **Claude:** `src/claude.js` uses `@anthropic-ai/sdk`, loaded dynamically, with `claude-sonnet-5-5`, effort `low`, and `fallbacks: "default"` under beta `server-side-fallback-2026-07-01`. Every caller falls back to the offline behaviour.
  - Model and SDK were the user's choices.
  - Load `claude-api` before touching this file.
- **Theme:** every value lives in `src/theme.css`. Contrast was checked by hand. Keep text at 4.5:1 and UI edges at 3:1 in both themes.
- **Timer:** the Start timer is in memory only (`src/now.js`) and resets when the Now Step changes. That's deliberate.
- **Testing:** the Playwright scripts used for testing lived in a throwaway scratchpad and weren't committed. Use `webapp-testing` to rebuild them. Preinstalled Chromium is at `/opt/pw-browsers/chromium`.
