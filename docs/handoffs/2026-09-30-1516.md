## Things to know before changing code

- **CSP:** production builds only allow `connect-src 'self' https://api.anthropic.com`. Any new network host must be added to the policy in `vite.config.js`, or the call is silently blocked. Dev mode has no policy, so always test the production build (`npm run build` then `npx vite preview`).
- **Merging:** AGENTS.md says to merge ready PRs yourself. Merging to `main` redeploys Pages and replaces any prototype deploy.
- **Deploying a prototype branch:** run `deploy.yml` with `workflow_dispatch` on that branch. The branch must be allowed under the github-pages environment rules, and it should include the latest `main`, so the live app doesn't lose fixes while the prototype is up.
- **Sandbox gotcha:** `pkill -f "vite preview"` inside a longer shell command kills that shell, which exits with code 144. Run it on its own, or not at all.
- **Test scripts:** the Playwright scripts were in a throwaway scratchpad and are gone. Rebuild them with `webapp-testing`. The fake speech engine that mimics the S23 (every growing phrase sent as a final result) is described in PR #5.
